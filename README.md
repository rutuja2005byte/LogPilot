# LogPilot



## Run LogPilot

**Prerequisites:** Docker Desktop and the LogPilot project.

```bash
docker compose up -d --build
```

**Access:**
- App: http://localhost:3000
- Kibana: http://localhost:5601
- Elasticsearch: http://localhost:9200

**Stop:**
```bash
docker compose down
```

**Check containers:**
```bash
docker compose ps
```
